# 版本管理

版本管理页不负责重新介绍整个协议，它主要回答三个更具体的问题：

1. 当前公开可见的版本有哪些。
2. 当前应该从哪个入口阅读“正在生效的公开能力面”。
3. 当前版本文档里哪些内容值得优先看。

<div class="version-switch">
  <a href="/nnrp-doc/zh/protocol/v1/">
    <strong>NNRP/1（预览）</strong>
    正式版尚未冻结前，当前公开预览能力统一从这里呈现。后续若出现新的预览版，这个入口会直接切到新的当前版本内容。
  </a>
</div>

当前规则：

1. 使用者默认应从 `NNRP/1（预览）` 进入，而不是直接记某个 preview 编号。
2. 某个 preview 的具体编号不再作为用户主入口组织方式。
3. 如果一个主题本身是跨版本的全局概念，应放在主文档路径中，而不是绑进某个 preview 页里。
