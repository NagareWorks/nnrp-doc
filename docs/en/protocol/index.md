# Versions and Compatibility

The user-facing documentation path explains global concepts first and versions second. Version pages should not redefine the whole protocol. They should answer three narrower questions:

1. Which public version tracks are currently exposed.
2. Which entry currently carries the public protocol surface people should read first.
3. Which parts of the current version path deserve attention first.

Current rules:

1. Readers should enter through `NNRP/1 (Preview)` rather than memorizing the latest preview number.
2. Preview-numbered paths are no longer the primary way to organize the user-facing docs.
3. Cross-version concepts belong in the main user path, not inside one preview branch.
