# Protocol Design

The site keeps the following versioned design documents:

1. `NNRP/1-preview1`
2. `NNRP/1-preview2`
3. `NNRP/1-preview3`

Index notes:

1. `v1-preview1` captures the minimal runnable protocol skeleton.
2. `v1-preview2` captures the preview2-stage design freeze for the richer data plane, typed payloads, and multi-transport binding. The emitted code-level wire identity frozen there is `NNRP/1.0`.
3. `v1-preview3` captures the profile-neutral public layer and the multi-session model.
